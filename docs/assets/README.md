# Homepage artwork

- `pgadmin-jr.svg` and `pgadmin-jr.ico` are unchanged copies of the current
  application artwork in `assets/icons/`. Refresh them together when it changes.
- `pgadmin-jr-racer.svg` is the original elephant-in-a-racing-car artwork,
  recovered unchanged from `assets/icons/alt-pg-admin.svg` in commit
  `7283e013f97505c1a06af16c9d245f01afbe3ecd`. Hans supplied the artwork for this
  project. It is used as a homepage illustration; the current application icon
  remains the compact elephant head.

All assets are local to the static homepage. No image service or external font
provider is required.
