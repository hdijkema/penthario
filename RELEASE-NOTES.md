## A lightweight PostgreSQL administration tool.

## *Less machinery. More magic.*

Penthario brings SQL editing, database browsing and everyday administration 
into a focused desktop application. Its C++/FLTK interface is designed for 
quick startup and responsive interaction.

## Highlights

- **A workspace that fits your workflow.** Independent query tabs, dockable panels,
  and remembered window sizes, positions and layout, including per-monitor
  configurations. Saved tabs retain their SQL, names and database targets.
- **Dark by default.** Choose Dark, Light or Classic, or customise the appearance
  with local CSS. Existing saved theme choices are preserved.
- **A clearer database browser.** Separate groups for tables, views, materialized
  views, sequences, foreign tables, functions, procedures and trigger functions.
  Function overloads show their signatures; object properties and definitions
  are available for inspection.
- **Database renaming from the context menu.** Rename a database and keep its
  query-tab targets in sync. Active queries must be stopped first; the dialog
  explains how existing connections and transactions are handled.
- **Practical SQL and result tools.** Syntax highlighting, search and replace,
  completion, query history, categorised saved queries, execution plans,
  clipboard copying, and CSV/XLSX export, including full-result export beyond
  the on-screen preview.
- **Everyday administration.** Backup and restore, database creation and deletion,
  server roles, database privileges, and VACUUM, ANALYZE and REINDEX.
- **Desktop packages.** Windows installer and portable ZIP, Apple Silicon macOS
  DMG, Debian amd64/ARM64 packages and an x86_64 Flatpak bundle. The macOS build
  has been reported working out of the box on a MacBook Air M1.

The interface is available in Dutch, English and German.
